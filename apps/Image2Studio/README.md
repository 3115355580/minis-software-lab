# Image2Studio

成品级 Android image2 生图客户端，支持 OpenAI 兼容图片接口。

当前版本：`2.2.0` / `versionCode 10`

## v2.2.0

- 修复顶部被系统状态栏遮挡：页面增加安全区 padding。
- 彻底取消大 Hero，改为更接近手机 App 的小 AppBar + 单页创作面板。
- 当前结果默认折叠，生成后才展开，避免底部导航遮挡。
- 底部导航保留，但页面底部 padding 增大，减少遮挡。
- 文生图参数继续保持一行：比例 / 清晰度 / 数量。

## 参数规则

比例：`Auto`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`

清晰度：`Auto`、`4K`

## 权限

- `INTERNET`

无通讯录、短信、定位、相机、相册读写等危险权限。
