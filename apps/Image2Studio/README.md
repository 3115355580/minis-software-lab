# Image2Studio

成品级 Android image2 生图客户端，支持 OpenAI 兼容图片接口。

当前版本：`2.1.1` / `versionCode 9`

## v2.1.1

- 删除顶部参数说明芯片，不再展示 Auto/4K 等说明标签。
- 删除“陕西咸阳520”这类具体示例，占位改为通用提示。
- 文生图页参数置顶：比例 / 清晰度 / 数量 横向一行。
- 图生图页参数同样横向一行。
- 继续保持 App 化布局：顶部小品牌栏、底部导航、卡片工作区。

## 参数规则

比例：`Auto`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`

清晰度：`Auto`、`4K`

`Auto` 清晰度不传 `size`；`4K` 按实测尺寸传：

- 16:9 → `3840x2160`
- 9:16 → `2160x3840`
- 1:1 → `2880x2880`
- 4:3 → `3200x2400`
- 3:4 → `2400x3200`
- Auto → `2880x2880`

## 权限

- `INTERNET`

无通讯录、短信、定位、相机、相册读写等危险权限。
