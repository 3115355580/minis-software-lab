# Image2Studio

成品级 Android image2 生图客户端，支持 OpenAI 兼容图片接口。

当前版本：`2.2.1` / `versionCode 11`

## v2.2.1

- 底部导航改为实体不透明 TabBar，类似微信底栏，不再透出下面内容。
- 内容底部 padding 加大，避免底部导航遮挡。
- 图生图选择参考图后显示缩略图。
- 每张参考图支持单独删除。

## 参数规则

比例：`Auto`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`

清晰度：`Auto`、`4K`

## 权限

- `INTERNET`

无通讯录、短信、定位、相机、相册读写等危险权限。
