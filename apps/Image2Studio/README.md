# Image2Studio

成品级 Android image2 生图客户端，支持 OpenAI 兼容图片接口。

当前版本：`2.1.0` / `versionCode 8`

## v2.1.0

- UI 改成更像移动 App：顶部小导航、品牌区、底部 Tab、卡片内容、画廊历史。
- 降低“大网页标题”感，使用底部导航切换文生图 / 图生图 / 历史 / 设置。
- 保留 Java Bridge：原生负责请求、选图、历史持久化、保存系统相册。

## 参数规则

比例：

- `Auto`
- `16:9`
- `9:16`
- `1:1`
- `4:3`
- `3:4`

清晰度：

- `Auto`
- `4K`

`Auto` 清晰度不传 `size`；`4K` 按实测尺寸传：

- 16:9 → `3840x2160`
- 9:16 → `2160x3840`
- 1:1 → `2880x2880`
- 4:3 → `3200x2400`
- 3:4 → `2400x3200`
- Auto → `2880x2880`

## 权限

- `INTERNET`

无通讯录、短信、定位、相机、相册读写等危险权限。
